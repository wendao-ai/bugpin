# Changelog 1.0.28

Widget 表单瘦身（lula 2026-06-01）。

## ✨ Features

### 「标题 + 详细描述」合并为单「问题」字段

之前两个 input 分开录入冗余且占空间，多数用户直接在 title 里写完，description 留空。改成单个 `<textarea>` 双向绑定 `formData.title`，placeholder 引导「请描述您遇到的问题（必填）」。

- 校验沿用：min(4) chars，由后端 `widget/submit.ts` schema 兜底
- `FormData.description` 字段保留（兼容已存在的草稿数据），UI 不再编辑

### 优先级 + 反馈类型改 button radio

原来「优先级」是 `<select>` 下拉，遮挡且需要二次点击。和已经是 radio 的「类型」统一改成 button-like radio：

- `role="radio"` + `aria-checked` 保留 a11y
- 选中态：主题色背景 + 反色文字
- 同一行展开（窄屏自动换行），节省垂直空间

### 截图 + 详情 Tab 合并

原本「详情 / 截图」两 Tab 切换增加心智负担，且 70% 用户只用其中一个。现改成：

- 单页平铺：问题 → 类型/优先级 → 姓名/邮箱 → 截图
- 姓名 + 邮箱挤同一行（grid 两列）
- 截图区域内联在表单底部，不再独占 Tab

新增 **`ScreenshotInline.tsx`** —— `ScreenshotManager` 的紧凑变体：
- 紧凑按钮条 + 3 列缩略图 grid（替代 2 列大图）
- 缩略图 hover overlay 显示标注/删除按钮（原来固定占行）
- 保留拖拽上传、文件选择、屏幕截图能力

### 粘贴上传图片（Ctrl/Cmd+V）

`WidgetDialog` 在 `document` 上挂 `paste` 监听：

- 从 `e.clipboardData.items` 提取 `kind === 'file' && type.startsWith('image/')` 的文件
- 通过自定义事件 `bugpin:paste-file` 转发给 `ScreenshotInline`
- 复用 `processFile` 走和拖拽一样的校验 / 缩略图 / Add 流程
- 在 textarea 里粘贴文本不受影响（只拦截 file 类型）

## 🔧 Internal
